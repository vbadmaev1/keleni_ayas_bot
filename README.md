# keleni_ayas — бот для аудирования калмыцкой речи

Telegram-бот на записях **INEL Kalmyk Corpus 1.3** (Университет Гамбурга,
CC BY-NC-SA 4.0): 55 текстов, 2 076 предложений, ~4,5 ч речи (у 48 текстов
есть звук), дербетский и торгутский говоры, переводы на русский и английский.

## Что умеет
- **Все записи**: каталог по жанрам (фольклор, рассказы, разговор) → карточка
  текста → вся запись / по предложениям / текст с переводом постранично.
- **Случайная запись** и **случайное предложение**.
- **По предложениям**: голосовое + текст и перевод под спойлером, ◀️ 🔁 ▶️,
  **🐢 0.75×** (замедление ffmpeg, кешируется).
- **Диктант**: короткое предложение (≤ 6 с), пользователь пишет услышанное,
  бот размечает ошибки по словам (без ә/ү/һ тоже засчитывается).
- **Угадай перевод**: 4 варианта.
- **Поиск**: любой текст в чат, поиск сразу по кириллице, латинице, русскому
  и английскому; прощает я/ю/h вместо ә/ү/һ.
- **Распознавание**: пришлите голосовое, аудио или видео до четырёх минут — бот
  вернёт калмыцкий текст. Используется wav2vec2 r4 в формате ONNX int8
  и словарная языковая модель.
- **⚠️ Ошибка**: пользователь может прислать исправление текста, оно
  приходит админам и пишется в базу (`events`, kind=correction).
- Настройки: кириллица / латиница / обе, перевод ru / en / оба, спойлеры.

## Данные
```
tools/extract.py      EXB -> corpus/raw.json (предложения, слова, глоссы, таймкоды)
tools/to_cyrillic.py  транскрипция -> современная кириллица
tools/build_corpus.py raw.json + kalmyk.coma -> corpus/corpus.json, corpus/review_unknown.tsv
tools/build_audio.py  mp3 -> audio/full/*.ogg и audio/sent/<id>/NNN.ogg (Opus 32k, loudnorm)
```
Пересборка всего:
```
python3 tools/extract.py corpus/raw.json
python3 tools/build_corpus.py
python3 tools/build_audio.py corpus/raw.json
```

### Кириллица
Транскрипция раскрывается в варианты (редуцированная ə пишется/не пишется
и какой буквой, j+гласная → я/ю/йо, e → е/э, во втором проходе т/д, к/г, в/б),
победителя выбирает частотный словарь из todorxoi-bot
(`model/letters_vocab.tsv.gz`, 108 тыс. словоформ); каждое отступление от
правила по умолчанию штрафуется. 91 % слов нашлись в словаре; остальное
(диалектизмы, заимствования, имена) — в `corpus/review_unknown.tsv`.
Ручные правки — `corpus/overrides.tsv` (`латиница<TAB>кириллица`), затем
`build_corpus.py`.

### Аудио
432 МБ mp3 → 69 МБ (целиком) + 51 МБ (1 896 предложений). Таймкоды в корпусе
верны на уровне предложений; у двух текстов (KSG_2008_Perfume, SGC_2007_Kalmyk)
они фиктивные — для них только запись целиком. У нескольких длинных записей
расшифрована только часть — бот это пишет в карточке.

## Запуск
Переменные окружения (как в todorxoi-bot):

| переменная | что |
|---|---|
| `BOT_TOKEN` | токен бота, обязательно |
| `ADMIN_IDS` | id админов через запятую: `/stats`, правки текста |
| `DATA_DIR` | база, логи, кеш 🐢; по умолчанию `./data` (как в todorxoi-bot), на хостинге — постоянный диск |
| `LOG_LEVEL` | `INFO` по умолчанию |

В `DATA_DIR` бот пишет:
- `bot.sqlite` — пользователи, настройки, file_id, события, ответы в тестах;
- `events.jsonl` — те же события построчно (поиск, прослушивания, правки);
- `bot.log` — лог (ротация, 5 × 2 МБ), он же в stdout;
- `slow/` — замедленные версии предложений.

```
pip install -r requirements.txt   # системный ffmpeg для замедления записей
python -m bot.main
```
Аудио в Ogg Opus лежит в `audio/`. Размер исходного корпуса INEL — около 120 МБ.
Проверка без сети: `python tests/smoke.py`.

## Лицензия данных
Записи, расшифровки и переводы — INEL Kalmyk Corpus 1.3, Universität Hamburg,
CC BY-NC-SA 4.0 (https://creativecommons.org/licenses/by-nc-sa/4.0/).
Аудио в `audio/` и кириллица в `corpus/corpus.json` — производные от корпуса
под той же лицензией; использовать только некоммерчески, со ссылкой на источник.

## Дополнительный аудиокаталог

`corpus/additional.json` содержит архивные сказки, записи из собрания
Национальной библиотеки им. А. М. Амур-Санана, материалы VLACH и выпуски
калмыцкого телевидения. В карточках указаны ссылки на источники, когда они
есть. Записи и тексты из этих подборок атрибутируются отдельно от INEL.

- `audio/full/catalog_*.ogg` — полные записи из архивных и библиотечных
  подборок и локального редактора.
- `audio/preview/catalog_tv_*.ogg` — короткие отрывки телевизионных выпусков.
  Полный выпуск открывается по ссылке в карточке. Таймкоды в тексте
  относятся к исходному выпуску.
- `transcript_kind`: `reviewed` — вычитано вручную, `book` — отрывок
  сопоставлен с печатным текстом, `automatic` — черновик распознавания или
  автоматически обработанные субтитры. Эти статусы видны в боте.

## Распознавание речи
На Linux x86-64 с Python 3.11 зависимости распознавания доступны готовыми
wheels. Пакет `camel-kenlm` предоставляет модуль `kenlm` для CTC-декодера,
а `imageio-ffmpeg` поставляет программу для извлечения звука.

ONNX модель и языковая модель загружаются при первом запросе в `DATA_DIR/asr/`
из [релиза asr-r4](https://github.com/vbadmaev1/keleni_ayas_bot/releases/tag/asr-r4).
SHA-256 обеих загрузок проверяется перед использованием. В релизе лежат
`model_int8.onnx` (~303 МБ) и `lm_final.arpa` (~24 МБ); сами бинарные файлы
не хранятся в истории git. Первый запрос на чистом `DATA_DIR` потребует скачать
около 327 МБ; постоянный том `./data:/data` сохраняет их между перезапусками.

Защита по умолчанию ограничивает файл 20 МБ и четырьмя минутами, очередь — двумя
запросами, распознавание идёт по одному заданию и двум CPU-потокам. На пользователя
действует пауза 20 секунд и лимит 20 записей в день. Модель не загружается, когда
контейнеру не хватает свободной памяти; после 10 минут простоя она выгружается.
Если памяти мало для LM, бот вернёт понятную ошибку. ASR можно отключить через
`ASR_ENABLED=0`, LM — через `ASR_LM_ENABLED=0`.

В Docker Compose настройки можно переопределить переменными окружения:
`ASR_MAX_SEC`, `ASR_MAX_MB`, `ASR_THREADS`, `ASR_QUEUE`,
`ASR_USER_COOLDOWN`, `ASR_USER_DAILY`, `ASR_MIN_FREE_MB`.
Для проверки: `python tests/asr_test.py` и `python tests/smoke.py`.
