# keleni_ayas — бот для аудирования калмыцкой речи

Telegram-бот на записях **INEL Kalmyk Corpus 1.3** (Университет Гамбурга,
CC BY-NC-SA 4.0): 55 текстов, 2 076 предложений, ~4,5 ч речи (у 48 текстов
есть звук), дербетский и торгутский говоры, переводы на русский и английский.

## Что умеет
- **Все записи**: каталог по жанрам (фольклор, рассказы, разговор) → карточка
  текста → вся запись / по предложениям / текст с переводом постранично.
- **Случайная запись** и **случайное предложение**.
- **По предложениям**: голосовое + текст и перевод под спойлером, ◀️ 🔁 ▶️,
  **🐢 0.75×** (замедление ffmpeg, кешируется).
- **Диктант**: короткое предложение (≤ 6 с), пользователь пишет услышанное,
  бот размечает ошибки по словам (без ә/ү/һ тоже засчитывается).
- **Угадай перевод**: 4 варианта.
- **Поиск**: любой текст в чат, поиск сразу по кириллице, латинице, русскому
  и английскому; прощает я/ю/h вместо ә/ү/һ.
- **⚠️ Ошибка**: пользователь может прислать исправление текста, оно
  приходит админам и пишется в базу (`events`, kind=correction).
- Настройки: кириллица / латиница / обе, перевод ru / en / оба, спойлеры.

## Данные
```
tools/extract.py      EXB -> data/raw.json (предложения, слова, глоссы, таймкоды)
tools/to_cyrillic.py  транскрипция -> современная кириллица
tools/build_corpus.py raw.json + kalmyk.coma -> data/corpus.json, data/review_unknown.tsv
tools/build_audio.py  mp3 -> audio/full/*.ogg и audio/sent/<id>/NNN.ogg (Opus 32k, loudnorm)
```
Пересборка всего:
```
python3 tools/extract.py data/raw.json
python3 tools/build_corpus.py
python3 tools/build_audio.py data/raw.json
```

### Кириллица
Транскрипция раскрывается в варианты (редуцированная ə пишется/не пишется
и какой буквой, j+гласная → я/ю/йо, e → е/э, во втором проходе т/д, к/г, в/б),
победителя выбирает частотный словарь из todorxoi-bot
(`model/letters_vocab.tsv.gz`, 108 тыс. словоформ); каждое отступление от
правила по умолчанию штрафуется. 91 % слов нашлись в словаре; остальное
(диалектизмы, заимствования, имена) — в `data/review_unknown.tsv`.
Ручные правки — `data/overrides.tsv` (`латиница<TAB>кириллица`), затем
`build_corpus.py`.

### Аудио
432 МБ mp3 → 69 МБ (целиком) + 51 МБ (1 896 предложений). Таймкоды в корпусе
верны на уровне предложений; у двух текстов (KSG_2008_Perfume, SGC_2007_Kalmyk)
они фиктивные — для них только запись целиком. У нескольких длинных записей
расшифрована только часть — бот это пишет в карточке.

## Запуск
Переменные окружения (как в todorxoi-bot):

| переменная | что |
|---|---|
| `BOT_TOKEN` | токен бота, обязательно |
| `ADMIN_IDS` | id админов через запятую: `/stats`, правки текста |
| `DATA_DIR` | база, логи, кеш 🐢; по умолчанию `./state`, на хостинге — постоянный диск |
| `LOG_LEVEL` | `INFO` по умолчанию |

В `DATA_DIR` бот пишет:
- `bot.sqlite` — пользователи, настройки, file_id, события, ответы в тестах;
- `events.jsonl` — те же события построчно (поиск, прослушивания, правки);
- `bot.log` — лог (ротация, 5 × 2 МБ), он же в stdout;
- `slow/` — замедленные версии предложений.

```
pip install -r requirements.txt   # + ffmpeg в системе
python -m bot.main
```
Аудио (`audio/`, ~120 МБ) лежит в репозитории: на хостинге исходных mp3 нет.
Проверка без сети: `python tests/smoke.py`.
